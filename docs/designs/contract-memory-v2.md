# 合同记忆 v2 数据与调用规范

版本 contract-v2；先完成离线验证，真实抽取/评测须经过测试包审查。

|层级|业务语义|证据/生效|
|---|---|---|
|L0|真实业务证据、对话、读取记录|不可变来源|
|L1|风险处置案例；明确长期偏好声明|保存反馈即可作为本人同团队案例；偏好尚未生效|
|L2|有条件的处置方法|两个不同合同空间或明确复用指令；用户确认|
|L3|跨场景审查原则、交付/称呼偏好|明确长期声明或正式经验；用户确认|

完整提示词见 `MemoryCore/src/contract-memory/prompts.ts`。统一采用角色、输入、类型、排除、工作流、冲突、结构、示例、成功标准；保持 JSON 输出。

权威事件字段由 OpenHarvey 保存反馈事务绑定，Core 用受控 review-events 接口接收。稳定事件 ID 对重复投递幂等；同一事项/合同版本的重复报告按一个案例计数。最新反馈版本决定当前状态，待处理退出参考，历史版本保留。

案例查询跨同用户同团队 Task；原通用桥接仍限当前 Task。OpenHarvey 在发给模型前及返回后检查历史合同访问、来源版本、成员状态。风险卡片和只读 Agent 脚本共用检索服务；最多三条，明确参考条件与差异。

v1 条目保留为历史，所有新版检索/提炼只读 v2。旧反馈仅提供只读预检；不自动回灌或用旧记忆正文伪造批复。后台候选保护、共享审核、版本检查及删除标记继续适用。

业务反馈保存成功与记忆同步成功分别展示；失败可重试，原反馈不丢失。个人称呼不进入团队共享。正式审批、Word 修订/执行事件和 E2B 不纳入本轮。
